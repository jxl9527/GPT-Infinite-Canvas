# 三阶段输入输出契约

## 阶段 01｜前置检查

- 输入：D5 锁定视角；可选同视角 SU 参考。
- 动作：只分析构图和当前视角可见的 SU 细节。
- 输出：左置意见卡。
- 禁止：生图、改相机、改建筑结构、自动进入下一阶段。

## 阶段 02｜场景优化

- 输入：结构与构图依据图；可选风格参考图。
- 浏览器人工批量：提示词与生图保留为两个独立人工动作。
- Codex 自动运行：一次授权后连续执行“生成并登记提示词卡 → 读取已批准提示词 → 生图 → 登记参考效果图”，不要求二次选择动作。
- 提示词卡是 Codex 自动运行的中间检查点，不代表该任务项已完成。
- 结构依据是唯一几何基准；风格图不提供建筑造型。
- 输出图是场景目标/参考效果，不冒充最终 D5 成图。

## 阶段 03｜最终玻璃深化

- 输入：最终 D5 完整图且仅一张；不得使用蒙版或 SU 图。
- 只深化玻璃通透、反射、层次和室内暖光关系。
- 原尺寸、比例、构图和非玻璃区域必须不变。
- 输出候选图并校验；最终采用必须由人工选择。

三个阶段可独立进入，不设置跨阶段自动门禁。
