# 暂停、恢复与执行通道接管

1. 读取当前 Run 和每个 RunItem 的状态、检查点、幂等键及租约。
2. `completed`、`validation-completed` 及更后检查点不得重复提交；场景优化的结构风险候选登记后，服务若把同一项退回 `prompt-approved / queued`，表示已安全安排下一候选，不是重复提交旧结果。
3. `generation-submitted` 项先查询/等待结果；不得切换执行器后再次生图。
4. Codex 自动运行不可用时默认暂停；仅在用户确认后把未完成项交给浏览器人工批量。
5. 浏览器人工批量完成部分项后，Codex 自动运行仅恢复 `queued` 或明确可重试的失败项。
6. 场景优化的结构风险候选先保留并按单图额度自动补生；单图额度用尽后记录失败并继续下一视角。只有批次总额度用尽、源哈希变化、最终玻璃结构风险、租约冲突或来源越界时停止并报告。
7. 恢复后逐项串行执行，每次写入后重新读取状态。
