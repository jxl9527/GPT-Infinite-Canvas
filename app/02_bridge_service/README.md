# P1 正式桥接服务

当前版本：`0.2.0`。仅监听 `127.0.0.1:3220`，API 基础路径为 `/api/v1`。

## 已实现

- 版本化任务模型与 TypeScript 共享类型；
- 回环监听、自有随机令牌和来源校验；
- 严格单任务锁；
- 不可逆提交状态；
- 原子 `task.json` 写入和 `events.jsonl` 事件账本；
- 服务重启后恢复未完成任务；
- 结果元数据 SHA-256 幂等；
- 附件文件创建后哈希复核和受限读取；
- 结果 data URL 格式与文件头校验、任务级写入锁、原子落盘和结果索引；
- 完成前重新核验结果文件路径、大小和 SHA-256；
- 脱敏 JSONL 日志和诊断 JSON 导出；
- 创建、查询、领取、状态、人工接管和完成的 v1 路由骨架。

## 配套状态

- P1 正式浏览器扩展已接入共享协议和 v1 API；
- 发布包、独立安装、升级回滚、脱敏诊断和备份恢复脚本已完成验证；
- 当前等待 10 次真实网页验收达到至少 8 次自动完成。

## 本地运行

从 `03_本地应用` 执行：

```powershell
npm install
npm test
pwsh.exe -File .\05_installer_and_ops\Start-P1.ps1
```

默认运行数据进入本目录的 `runtime`，已从版本库排除。真实项目路径后续通过 `GPT_CANVAS_PROJECT_ROOT` 显式指定。
