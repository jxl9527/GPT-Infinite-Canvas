# GPT Canvas Bridge（P1）

当前版本：`1.5.16`。正式浏览器扩展连接本机 `127.0.0.1:3220` 的桥接服务，并以 ChatGPT 完成单任务桥接闭环。ChatGPT 回图只读取最新助手回复中的大尺寸位图，忽略浏览器扩展注入的小图标；审查型任务会保存最新助手文字并回写画布。生图任务若只返回 `/mnt/data/...` 内部图片路径，会自动纠偏一次并要求改为可见图片，仍失败时再安全暂停。画布会读取扩展真实版本，旧扩展未重载时禁止创建新任务并明确提示目标版本。Google Flow 适配因网页稳定性不足已冻结：底层协议与适配代码保留用于后续验证，但画布不再创建新的 Flow 任务，正常用户界面也不显示 Flow 入口。

## 加载前

1. 先停用或移除旧的 `GPT WEB CANVAS / P0` 扩展，避免同一 ChatGPT 页面出现两套浮层；
2. 在可见终端中使用 `05_installer_and_ops/Start-P1.ps1 -SkipBuild` 启动 P1 服务；终止时按 `Ctrl+C`；
3. 确认 `http://127.0.0.1:3220/health` 可访问。

## Chrome 加载

1. 打开 `chrome://extensions/`；
2. 开启“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择本目录下的 `dist` 文件夹；
5. 固定 `GPT Canvas Bridge` 图标，打开扩展并保存服务地址与令牌。

发布 ZIP 仅用于归档和迁移。Chrome 开发者模式加载时，应先解压，再选择包含 `manifest.json` 的文件夹。

## 安全边界

- 页面消息必须绑定任务 ID 和领取任务的标签页；
- 自动自愈绑定仅允许处于 `opening-chat` 的非终态任务，防止其他 ChatGPT 标签页抢占任务；
- 服务端在网页点击前锁定 `submitted`，同一任务不得重复提交；
- 历史图片只保存 URL 哈希基线，不把旧图写入新任务；
- 只收集助手对话轮次中的图片；服务端再次拒绝与任一输入附件 SHA-256 完全相同的结果；
- 自动收图失败或 10 分钟未识别稳定结果时转入人工接管，不静默丢失状态；
- 任务结果只写入该任务的独立目录，不覆盖原附件。
