# GPT Infinite Canvas

0.6.0 简化分支：默认以固定提示词图库 → 图片画布 → ChatGPT 网页生成作为主流程，最多两项独立任务并发。详见 [简化版验收说明](docs/简化版验收说明.md)。以下旧阶段工作流介绍适用于兼容入口。

面向建筑与视觉设计工作的本地无限画布，把参考图、结构基准、批注、提示词和生成结果放进同一个可追溯的工作空间。

它适合需要反复比较方案、严格保护原始结构、管理多轮改图结果的设计师。产品提供两个执行通道：“浏览器人工批量”由设计师通过浏览器扩展确认和批量执行；“Codex 自动运行”由 Codex 插件在一次授权单范围内运行。场景优化中的结构风险候选会被保留并按单图额度自动补生，单图额度用尽后记录失败并继续下一视角，不再因首张候选失败退出整批。两种方式共用同一画布、批次、版本和导出记录，结果作为新版本回到画布，不覆盖原图。实验性的 Google Flow 适配当前冻结并默认隐藏。

## 你可以用它做什么

- 在无限画布中整理大量参考图、过程图和生成结果。
- 一次选择图片文件夹，按文件名自然排序导入，并在画布中纵向展开。
- 无需预先准备项目文档，可直接创建空白项目并导入第一张图片。
- 可在项目登记簿中移除不再使用的项目；项目先移入本地回收目录，不会立即永久删除。
- 使用三阶段工作流：前置阶段、优化阶段、最终阶段；任一阶段都可直接开始，不要求补齐前序记录。
- 前置阶段中，每张已选 D5 视角都是独立文字任务，可为每张图明确配对一张同方向 SU 截图；不同视角不会互相比较。
- 优化阶段明确区分“结构底图”和“风格参考”：浏览器人工批量保留提示词与目标图两个独立动作；Codex 自动运行在一次授权后连续完成“提示词 → 生图”。
- 最终阶段只输入最终 D5 完整图，固定深化玻璃反射和内透，不要求蒙版、Transparent、AO、Material ID 或 SU 截图。
- 使用箭头、文字、画笔和框选四类标注表达修改意图。
- 使用撤销、重做和键盘微调安全修正画布操作。
- 在提交前预览最终提示词，减少无关项目背景对单次任务的干扰。
- 自动保留父子版本关系，直观看到每轮修改从哪里产生。
- 在图片节点上自动标记视角阶段与状态，并允许人工覆盖自动判断。
- 在画布空白处直接按住左键拖框选择多张图片，按当前阶段允许的动作严格串行发送到普通 GPT；`M` 仍可作为快捷入口。
- 为每个视角记录底图、候选版本、采用成果和标准交接记录。
- 通过“视角任务中心”按视角筛选待验收、需处理、已采用和已导出任务；候选最多两张同步缩放对比，五项人工验收全部通过后才允许采用。
- 新建空白项目时可从三个独立阶段直接开始，也可跳过启动器；右侧工具面板使用统一标准宽度，并在宽屏为画布让位、窄屏按视口自适应。
- 检测到另一窗口或 Codex 更新同一项目时暂停自动保存，先把本地改动保存为可恢复冲突草稿，再载入权威版本，不覆盖任何一方。
- 将提示词保存到本地仓库，复用常见的建筑图像工作流。
- 内置七张 V3 工作流提示词卡，围绕前置文字审查、优化阶段提示词与目标图、最终整图玻璃深化和继续项目组织。
- GPT返回的分析文字和提示词会作为可编辑文字卡放在原图左侧，生成图保持在原图右侧；可选中文字卡中的一段继续发送、复制或存入提示词库。
- 将一组图片建立为 GPT 串行批次，自动逐张发送统一提示词、收集结果并放回各自原图右侧。
- 通过右侧“执行通道”选择浏览器人工批量或 Codex 自动运行；Codex 自动运行默认直接使用当前画布图片，也可切换为粘贴绝对路径或使用系统文件夹选择器导入新批次。场景优化按授权总额度为每张底图分配尝试次数，结构风险候选自动拒收并补生，单图额度用尽后继续下一视角；最终玻璃失败仍严格暂停。
- Codex 前置审查意见卡放在原图左侧，生成候选放在原图右侧；最终采用版本仍由人工选择。
- 导入项目需求 Markdown，在需要时为分析图或文生图补充背景。

## 典型工作方式

### 阶段一｜前置阶段

1. 框选一张或多张不同视角的 D5 图片；每张图片都会形成独立任务。
2. 如需审查 SU 可见细节，在每张 D5 图对应行选择一张 SU 截图；SU 截图不要加入 D5 框选。
3. 点击发送，逐视角返回“构图＋SU 可见细节”文字卡；本阶段不提供提示词生成或生图动作。

### 阶段二｜优化阶段

1. 可直接进入本阶段，将图片设为结构底图，风格参考可选。
2. 浏览器人工批量先执行“生成／优化提示词”，得到可编辑文字卡；确认后框选对应原图，在“执行通道 → 浏览器人工批量”中使用“批量按已返回提示词生成”。系统会先列出“原图 → 提示词卡”配对，仅在全部就绪时按各自提示词严格串行生图。
3. Codex 自动运行确认一次运行授权单后，自动生成并登记提示词，随后直接生成 D5 场景目标图；提示词卡仍保留在画布中供复核。

### 阶段三｜最终阶段

1. 可直接导入一张或多张最终 D5 完整效果图。
2. 系统逐张生成完整画幅玻璃深化图；宽高比异常时暂停，不裁切结果。
3. 人工确认没有裁切、扩图、结构或配景漂移后，选择一个或多个玻璃版本。
4. 设置用户指定导出文件夹并批量导出；文件按 `视角名_玻璃整图_01` 顺延，不覆盖、可续传。
5. 全部选定成果导出成功后，画布任务结束；Photoshop 由用户在画布之外人工处理。

普通 GPT 是默认生成目标，无需配置地址。若某个专属 GPT 已经验证稳定，可在“GPT 工作台 → 生成目标”中主动启用并填写 `https://chatgpt.com/g/g-…`；批次开始后目标会被冻结，途中修改不会改变当前批次。

画布是项目状态的唯一依据，负责图片选择、阶段附件组合、规则版本、串行队列和结果回收；普通或可选专属 GPT 只执行本轮任务。分析和提示词任务返回文字卡，生图任务返回完整图片。每次阶段任务都会携带 `D5-RULESET-3.0`、项目摘要和本轮附件清单，不依赖聊天历史记忆。

最终阶段的“标记采用”只把验收通过的玻璃深化版本加入待导出集合。批量导出使用用户指定的任意有效绝对文件夹，不要求固定目录名称；同名文件自动顺延，重复版本按 SHA-256 去重，部分失败保留成功状态并可继续。日志保存在画布项目的 `logs/final-glass-export.ndjson`，不强制写入用户目标文件夹。

对于“图一参考风格，图二为唯一结构依据”的任务，系统强调：

- 图一只提供色彩、材质、光影和表达方式；
- 图二是唯一建筑与场地基准；
- 不改变图二的建筑造型、数量、比例、朝向、视角和空间关系。

## 本地优先与隐私

- 画布数据、原始图片、批注、提示词和任务记录默认保存在本机。
- 本地服务只监听 `127.0.0.1`。
- 不读取或保存 ChatGPT Cookie、登录凭据或账号认证 Token。
- 不调用 ChatGPT 私有接口。批量队列必须由用户明确点击开始，严格串行；登录失效、网页验证或失败时自动暂停，不重复提交。
- `runtime`、日志、构建产物、测试图片和本地发布包均被 Git 忽略。
- 公开仓库不包含个人项目数据、个人知识库、运行令牌或本机绝对路径。

详见 [隐私与安全说明](docs/PRIVACY.md)。

## 快速开始

### 环境要求

- Windows 10 / 11
- Node.js 24 或更高版本
- Chrome 或 Microsoft Edge
- PowerShell 7

### 安装

```powershell
cd app
npm install
npm run build
npm run build:canvas

# 仅校验 Codex 插件与 12 个 MCP 工具
pwsh 05_installer_and_ops\Install-D5AICanvas-CodexPlugin.ps1 -ValidateOnly
```

构建完成后：

1. 双击 `app\05_installer_and_ops\Start-GPTCanvas.vbs` 启动画布；或运行桌面启动器安装脚本，固定使用 Chrome。
2. 在 Chrome / Edge 的扩展管理页开启开发者模式。
3. 加载 `app\03_browser_extension\dist` 作为已解压扩展。
4. 按 [安装与使用](docs/guides/安装与使用.md) 完成本地桥接配置。
5. 如使用 Codex 自动运行，运行 `pwsh app\05_installer_and_ops\Install-D5AICanvas-CodexPlugin.ps1`；桌面启动器安装脚本也会在检测到 Codex CLI 时安装插件。

默认地址：

- 画布：`http://127.0.0.1:3230`
- 本地桥接：`http://127.0.0.1:3220`

进入项目工作台后，可以直接输入名称创建空白项目，也可以先附加项目需求 Markdown。画布支持拖放图片、点击左侧“导入”，或点击“文件夹”快速导入整组图片；`Ctrl+Z / Ctrl+Y` 用于撤销和重做，方向键用于微调当前图片或批注。

项目登记页可直接复制当前服务正在使用的桥接令牌，避免误用测试目录中的同名令牌文件。

### Chrome 桌面启动器

源码环境可运行：

```powershell
pwsh app\05_installer_and_ops\Install-GPTInfiniteCanvas-DesktopLauncher.ps1
```

从 GitHub Release 下载并解压后，也可以直接双击 `05_installer_and_ops\Install-GPTInfiniteCanvas-DesktopLauncher.cmd`。桌面会生成“GPT 无限画布”快捷方式。双击后自动启动本地服务，并明确使用 Google Chrome 新窗口打开画布，不改变 Windows 的默认浏览器设置；Microsoft Edge 可以继续作为日常默认浏览器。

启动器图标基于 MIT 许可的 [Tabler Infinity](https://tabler.io/icons/icon/infinity) 设计，来源与许可证保存在 `app\05_installer_and_ops\assets\launcher`。

## 设计边界

GPT Infinite Canvas 是本地工作台，不是 ChatGPT 的替代客户端。网页结构变化、登录验证或站点安全策略可能需要用户接管；当网页状态不确定时，系统应停止自动操作，不重复提交任务。
