# 隐私与安全说明

GPT Infinite Canvas 采用本地优先的数据策略。

## 本地保存

以下内容默认只保存在用户指定的本地项目目录：

- 原始图片与派生图；
- 画布布局、批注和版本关系；
- 项目需求、提示词与任务记录；
- 本地服务日志和诊断信息。

这些目录已通过 `.gitignore` 排除，不应提交到公开仓库。

## 浏览器边界

- 浏览器扩展只处理用户主动发起的单次任务。
- 不读取或导出 Cookie、密码、ChatGPT 登录凭据或认证 Token。
- 不调用 ChatGPT 私有接口。
- 不绕过额度、速率限制、登录验证或网站安全策略。
- 页面状态不确定时停止自动操作，交由用户确认。

## Codex 插件边界

- B 模式只开放 D5 领域工具，不开放任意本机命令、任意项目 JSON 写入、任意目录扫描或源文件覆盖。
- 项目文件夹扫描只接受用户明确提供的绝对路径，拒绝磁盘根目录、符号链接和清单外文件；导入只复制确认资产。
- Bridge 在 `%LOCALAPPDATA%\D5AICanvas\bridge-connection.json` 写入不含 Token 的本机连接定位信息；MCP 据此从实际运行目录读取令牌。令牌不返回给 Codex 对话，也不写入诊断日志。
- 生图结果只允许从 Codex 默认生成目录或 `D:\CodexWorkspace` 读取，且必须是 40 MiB 以内的 PNG、JPEG 或 WebP 普通文件。
- 写操作受运行授权单、阶段、项目数、生成上限、幂等键、串行检查点和租约约束。
- 插件不得自动选择最终采用版本；删除、覆盖源资产和绕过状态机均不提供工具。

## 网络边界

本地服务默认只监听 `127.0.0.1`，不向局域网或公网开放。项目目前不包含遥测、广告、云账号和第三方分析服务。

## 公开前检查

- `.env`、Token、密钥和本地配置未被跟踪；
- `runtime`、日志、诊断包、测试图片和发布压缩包未被跟踪；
- 文档不含姓名、邮箱、学校/公司名称、个人知识库路径或本机绝对路径；
- Git 提交历史中不存在已删除的敏感文件。
