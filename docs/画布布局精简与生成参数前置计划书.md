## 3. 红框：合并顶部，压缩右侧标题

### 3.1 顶部只保留一条项目栏

桌面画布页建议高48—52px，替代截图中的两层应用栏。排列如下：

左侧：返回项目 / 项目名称 / 保存状态。
右侧：提示词库 / 导入图片 / 导出与设置。

- 画布页取消独占一行的品牌、CANVAS副标题、宣传语和“画布”当前页标签。品牌如需保留，只使用小图标融入同一栏，不再次加高。
- “提示词库”保留一处全局导航。提示词字段旁的“从图库复制”是明确的上下文操作，可保留，但不再增加第三处同类入口。
- 保存正常显示小型状态文字；保存失败/冲突必须显著、可处理，不能随正常状态一起隐藏。
- 项目长名称单行省略，悬停/聚焦可查看全名，不挤压操作按钮。
- 本轮只精简进入项目后的画布页面；图库与项目列表保留各自导航。切换图库再返回不得卸载正在运行的画布实例、重置队列或丢失草稿。
- 截图最上方应用外壳的小图标若属于宿主环境，不在修改范围；只处理项目内可控界面。

### 3.2 右侧去掉大标题堆叠

删除常驻的“图片渲染”小标题和独占大行的“已选择N张图片”。合并成一行紧凑上下文：

单选：`1张 · 6转角透视2_1.png`
多选：`已选3张 · 查看图片`

该行控制在约28—32px，文件名不折成多行；多选名单按需展开。其后直接进入“提示词 / 从图库复制”和编辑框，不再添加用途说明型标题。

未选图片但有活动任务时，显示“本轮任务”，继续可见队列和暂停/检查操作；没有任务也没选择时沿用明确的选图提示，不显示虚假的“已选0张”生成面板。

### 3.3 提示和状态压缩

- “已追加1个版本”等成功反馈用短时轻提示，不长期占一整条横幅；建议4秒后消失，任务记录仍保留。
- 保存冲突、连接失败、绑定异常、需要用户处理等持久问题保持可见，直到解决或明确关闭，不按成功提示计时消失。
- “仅发送选中图片和上方提示词，图库封面不上传”等说明收进字段帮助，不在主按钮下长期重复。
- 字数计数保留一处小字；运行任务数量放在队列标题，不再用多段文字重复相同信息。

## 4. 蓝框：左侧竖向工具栏

### 4.1 工具顺序

将原横栏整体迁移到画布左侧，不增加一份重复工具栏。推荐顺序：

| 组别 | 从上到下 |
| --- | --- |
| 选择与移动 | 选择V、平移H |
| 创建与标注 | 文字T、箭头A、画笔P、矩形R、颜色 |
| 编辑与视图 | 撤销、重做、适合画面 |
| 整理 | 整理/操作菜单 |

工具轨宽约48—56px，距画布左边12px、顶部12px；单个点击目标至少36×36px，间距4px。采用易辨认图标，悬停与键盘聚焦显示中文名称和快捷键；当前工具有稳定选中态，禁用态可识别。不要把横排文字旋转90度，也不要用含义不明的文字字符替代图标。

使用轻背景与细分组线，边框包裹实际工具高度。截图蓝色长框表达放置区域，不要求绘制一根贯穿画布的空白栏。

### 4.2 与画布的关系

- 工具栏是视口固定浮层，不随画布缩放或平移；适合画面计算考虑工具栏与右侧面板遮挡。
- 整理菜单、颜色选择器向右展开，空间不足时自动避让，不出屏、不遮住当前按钮。
- 原有中键、空格平移、多选、标注、撤销重做逻辑保留。工具栏点击、颜色与菜单操作不能触发底层框选或图片对比。
- 底部缩放控件、对象列表、图片选中工具条本轮不强行迁移；调整偏移避免与左侧栏重叠。
- 小高度窗口中工具轨可以内部滚动，菜单弹层不被滚动容器裁切。不要为容纳工具继续压缩点击目标。

## 5. 绿框：任务和版本设置前置

此处“任务与版本”特指图二中的两个生成参数，不是把下方任务结果列表搬到绿框。

### 5.1 直接操作布局

提示词编辑框下方、开始渲染按钮上方增加同一行两列控件：

| 左列 | 右列 |
| --- | --- |
| 同时生成 | 每张图生成 |
| 1 / 2 / 3 个任务 | 1 / 2 / 3 个版本 |

建议各列占一半宽度，间距8—12px，选择框高32—36px，标签使用12px左右文字。绿框是位置示意，不按截图约30px高度硬塞两层内容。删除原有“3个任务并发 · 每图1个版本”的重复摘要。

下方仅保留一行总量：`已选2张 · 共6个任务`，随后为“开始渲染”。无需再到“导出与设置”页面修改，两项常用参数在生成前持续可见。

### 5.2 保持现有业务语义

- 控件复用当前 prefs.concurrency、prefs.copiesPerImage 与 updatePreferences，不创建第二份局部状态。
- 保留现有默认值、持久化和服务端能力检测。bridgeSimpleConcurrencyLimit 未支持3时，仍不提供可提交的3档；不得因界面迁移绕过限制。
- 活动批次期间两个控件仍禁用，附近仅显示简短原因“本轮进行中，完成后可调整”。暂停不等于批次结束，不提前解锁。
- 队列存在但没有选图时仍可展示禁用参数；本轮参数以实际批次快照为准，不用无关草稿冒充正在运行的设置。
- 修改版本数只更新下次开始时的任务总数，不立即创建任务；现有“同样设置再生成”仍按原逻辑新增一次，不乘上当前每图版本数。
- 开始渲染的连接检查、保存冲突、空提示词和批次状态保护保持一致。
- 设置页面删除这两个重复控件和长段机制说明，保留导出目录、连接与兼容等低频功能。设置页返回主面板后参数、草稿和选区不变。

## 6. 面板尺寸与响应式

桌面右侧宽度沿用约330—355px，内边距建议16px；不为压缩标题而缩窄提示词阅读区。

标准1080p窗口下，提示词框建议初始240—300px高；在768px高窗口自动缩减，但正常布局不低于160px。参数和开始按钮应在主面板首屏出现，不能被结果列表挤到不可见处。

优先使用弹性布局：选图行紧凑，提示词可伸缩，参数与按钮保持可见，任务列表使用剩余空间滚动。极低高度允许面板整体滚动兜底，不把提示词、队列和整面板都强制做成嵌套滚动区。

- 1920×1080、1366×768：单层项目栏、左竖工具、右生成面板；参数与开始按钮无需滚动即可操作。
- 1024×768：保留主要操作，长项目名省略，低频导出/设置可收入更多菜单。
- 720px以下：沿用画布上方、操作面板下方的思路；两项参数在空间足够时仍两列，过窄则纵排。工具栏仍在画布左侧，必要时滚动；触控点击目标建议44px。
- 200%页面缩放检查按钮和标签可访问，不要求强行保持桌面首屏目标。
