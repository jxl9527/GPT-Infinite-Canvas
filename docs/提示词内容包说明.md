# 提示词内容包

用户提供清晰参考图后，由 Codex 提炼材质、光影、色彩、线条、氛围和表达方式。建筑体块、数量、比例、道路及场地边界必须遵循实际底图；图库封面仅供选风格，不随任务上传。

内容包格式为 `{"cards":[...]}`，每条包含：

- `title`：短标题，最多 40 字符。
- `content`：完整提示词，最多 20000 字符。
- `category`、`inputHint`：分类与适用底图。
- `coverPath`：制作清单中的本地封面路径；封面为 2 MiB 内 PNG、JPEG 或 WebP。
- `coverLabel`：如“用户参考图”；示意图须明确写“示意封面”。
- `id`：可选。更新既有卡片时填写其原有 ID；未提供则新增。

在 app 目录执行 `node scripts/create-prompt-pack.mjs 清单.json 输出目录`，得到可在提示词库页面导入的 JSON。脚本只读取指定文件，输出同名自动递增，并记录日志；不修改参考图。

每包 1—100 条、总大小不超过 20 MiB。导入前验证全部条目的主要格式，逐条保存；若部分失败，页面显示已成功条数。更新前保存库文件备份到 runtime/workbench/prompt-library-history。

当前内置六张基础文字模板使用明确标注的建筑示意封面。两张用户截图只作为布局参考，未从小缩略图虚构具体案例提示词。
