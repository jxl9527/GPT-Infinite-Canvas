# 安装与使用

## 1. 准备环境

安装 Node.js 24 或更高版本，并确认 PowerShell 7 可用：

```powershell
node --version
pwsh --version
```

## 2. 安装依赖并构建

```powershell
cd app
npm install
npm run build
npm run build:canvas
```

## 3. 启动画布

双击：

```text
app\05_installer_and_ops\Start-GPTCanvas.vbs
```

浏览器将打开 `http://127.0.0.1:3230`。

## 4. 加载浏览器扩展

1. 打开 Chrome / Edge 扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展”。
4. 指向 `app\03_browser_extension\dist`。
5. 在扩展弹窗中连接本地桥接服务。

## 5. 创建任务

1. 输入项目名称；项目需求 Markdown 为可选项。
2. 创建项目后，拖入图片或点击左侧“导入”。
3. 为图片分配结构基准、风格参考或编辑目标。
4. 添加必要批注。
5. 在任务预览中填写本轮修改要求。
6. 确认最终提示词后主动发送。

常用键盘操作：

- `Ctrl+Z`：撤销。
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做。
- 方向键：移动当前图片或批注 1 个单位。
- `Shift + 方向键`：移动 10 个单位。

生成出现登录、网页验证或扩展异常时，可以点击“结束当前任务”。如果任务已经发送到 ChatGPT，此操作只结束本地跟踪，不能撤回已发送内容。

停止服务时，双击 `app\05_installer_and_ops\Stop-GPTCanvas.vbs`。
