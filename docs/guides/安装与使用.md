# 安装与使用

## 1. 准备环境

安装 Node.js 24 或更高版本，并确认 PowerShell 7 可用：

```powershell
node --version
pwsh --version
```

## 2. 安装依赖并构建

```powershell
cd app
npm install
npm run build
npm run build:canvas
```

## 3. 启动画布

双击：

```text
app\05_installer_and_ops\Start-GPTCanvas.vbs
```

浏览器将打开 `http://127.0.0.1:3230`。

### 固定使用 Chrome 的桌面入口

如果 Windows 默认浏览器是 Edge，但希望无限画布始终使用 Chrome，运行：

```powershell
pwsh app\05_installer_and_ops\Install-GPTInfiniteCanvas-DesktopLauncher.ps1
```

如果使用 GitHub Release 中的安装包，解压后可以直接双击：

```text
05_installer_and_ops\Install-GPTInfiniteCanvas-DesktopLauncher.cmd
```

桌面将出现“GPT 无限画布”快捷方式。它会：

1. 检查并启动本地桥接服务。
2. 等待画布服务就绪。
3. 明确调用 Google Chrome 新窗口打开画布。
4. 保持系统默认浏览器设置不变。
5. 检测到 Codex CLI 时，校验并安装 D5 AI Canvas 本地插件；未安装 Codex 时浏览器人工批量不受影响。

如果桌面已经有同名快捷方式，安装脚本会先在桌面创建带时间戳的备份，再更新入口。

## 4. 加载 Chrome 浏览器扩展

1. 在 Chrome 中打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展”。
4. 指向 `app\03_browser_extension\dist`。
5. 在扩展弹窗中连接本地桥接服务。

每次点击扩展管理页的“重新加载”后，需要刷新已经打开的画布和 ChatGPT 页面，让新版内容脚本重新连接。

### 本地桥接令牌

正式运行令牌位于：

```text
app\02_bridge_service\runtime\bridge-token.txt
```

项目登记页右上角提供“复制桥接令牌”按钮。该按钮直接读取当前服务使用的令牌，是推荐方式。

不要复制 `output`、`.test-dist` 或 `playwright` 测试目录中的同名文件；这些令牌只属于隔离测试服务，粘贴到正式扩展会提示无效。令牌仅供本机扩展连接，请勿截图、上传或提交到 GitHub。

## 5. 安装 Codex 自动运行插件

先启动画布并在项目登记簿中打开一个项目，再运行：

```powershell
pwsh app\05_installer_and_ops\Install-D5AICanvas-CodexPlugin.ps1
```

脚本会先校验固定依赖和 12 个 MCP 领域工具，再备份已有 Codex 配置，通过本地插件市场安装 `d5-ai-canvas`。它不会使用 `npx -y` 临时下载运行时。仅做检查可加 `-ValidateOnly`。

在画布右侧打开“执行通道”：

1. 选 B 后默认使用“当前画布”：当前框选优先，没有框选时使用画布中已登记的 D5／导入图。只有需要导入新批次时，才切换到“项目文件夹”，粘贴绝对路径或点击“选择文件夹”调用 Windows 系统选择器。
2. 执行只读扫描，核对 D5、SU、风格参考和忽略通道；确认后复制到项目资产区。
3. 选择一个独立阶段和动作，填写批次生成总额度。场景优化默认按底图数量均分额度：结构风险候选会保留在画布并自动补生；该底图额度用尽后记录失败并继续下一视角。最终玻璃阶段仍在结构、尺寸或画幅校验失败时暂停。
4. 勾选授权确认并建立 B 批次；超出目录、阶段、项目数或生成上限时必须重新授权。
5. 在 Codex 中使用 `$run-d5-canvas-workflow`。前置意见卡自动放在原图左侧，生成候选放在右侧。
6. Codex 执行期间可“刷新结果”“安全暂停”；只有明确点击后才会切换到浏览器人工批量。人工通道暂停后也可明确交回 Codex，已完成或已提交项不会重复生成。

Codex 自动运行的最终玻璃深化只接受最终 D5 完整图，登记结果时必须通过原像素尺寸校验。Codex 不会自动勾选最终采用版本。

## 6. 创建任务

1. 输入项目名称；项目需求 Markdown 为可选项。
2. 创建项目后，拖入图片或点击左侧“导入”。
3. 选择前置、优化或最终阶段；三个阶段均可直接进入。
4. 添加必要批注。
5. 展开“GPT 工作台”；系统只显示当前阶段允许的动作。普通 GPT 默认可直接使用。
6. 在任务预览中填写本轮修改要求；如使用已验证的专属 GPT，再主动启用并填写其首页地址。
7. 确认最终提示词和附件身份后主动发送。文字结果会回到原图左侧，可编辑、选择并继续发送；生成图保持在原图右侧。

### 批量阶段处理

1. 使用默认选择工具，在画布空白处直接按住左键拖出选择框；也可以按 `M` 或点击左侧“批选”。
2. 在右侧选择统一阶段。浏览器人工批量中，前置阶段固定返回文字，优化阶段分为提示词和目标图两个动作，最终阶段固定返回玻璃深化完整图；Codex 自动运行中，优化阶段在一次授权后连续执行“提示词 → 目标图”。
3. 前置阶段框选项均视为独立 D5 视角；如需 SU 审查，在每张 D5 对应行选择 SU 截图，不要把 SU 图加入 D5 框选。
4. 优化阶段的提示词卡全部返回后，再框选对应原图，打开“执行通道 → 浏览器人工批量”，使用“批量按已返回提示词生成”。面板会逐项显示原图与绑定提示词卡；缺失或错配时按钮不可用。
5. 队列严格逐张执行；每个任务使用启动时冻结的独立提示词快照。登录、验证、比例异常或生成失败时会暂停，不重复提交。

专属 GPT 是可选项。启用并确认地址后会固定在本机并跨项目复用；已经开始的批次会固定使用启动时的目标。

### 固定工作流提示词

“GPT 工作台”内置七张 V3 固定卡：前置构图＋SU细节审查、有参考图场景提示词、无参考图场景提示词、粗提示词优化、D5目标图生成、最终整图玻璃深化和继续当前项目。点击“套用”会同时切换合适的阶段与动作。

GPT返回的分析和提示词会作为文字卡放在来源图左侧，与右侧的生成图分区。文字卡支持直接编辑、框选一段用于下一步、使用全文、复制以及存入项目提示词库；移除文字卡不会删除GPT原始任务记录。

### 阶段三：最终玻璃深化

最终阶段每个任务只输入一张最终 D5 完整效果图，不输入蒙版、Transparent、AO、Material ID、SU 截图或其他后期通道。GPT 必须返回同宽高比、同裁切的完整效果图。画布会拒绝比例不同的结果；比例相同但像素不同，会生成与原 D5 像素一致的 `_PS对齐` 副本。用户还需人工确认没有结构、配景、裁切或扩图异常。

### 选择与批量导出

最终玻璃图验收通过后，可为每个视角选择一个或多个版本。展开输入区的“最终导出”，设置用户指定文件夹的绝对路径并预览待导出数量，再执行批量导出。系统使用 `视角名_玻璃整图_01` 顺延命名，不覆盖同名文件；重复版本按哈希去重，部分失败保留成功记录并可继续。全部选定成果导出成功后，画布任务结束；Photoshop 由用户在画布外人工处理。

### 移除项目

在项目登记簿中点击“删除”，再点击“确认移除”。项目会移动到本地 `runtime/trash/projects` 回收目录，不会立即永久删除；兼容入口“原有项目”不能在工作台中删除。

常用键盘操作：

- `Ctrl+Z`：撤销。
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做。
- `M`：进入批量框选。
- 方向键：移动当前图片或批注 1 个单位。
- `Shift + 方向键`：移动 10 个单位。

生成出现登录、网页验证或扩展异常时，可以点击“结束当前任务”。如果任务已经发送到 ChatGPT，此操作只结束本地跟踪，不能撤回已发送内容。

停止服务时，双击 `app\05_installer_and_ops\Stop-GPTCanvas.vbs`。
