# 画布 V3 升级迁移说明

## 版本信息

- 版本：0.4.0
- 项目结构：schema 2.0
- 升级前基线：`2fbd96e V3 升级前回归基线`
- 原始项目处理原则：读取、迁移、另存；不删除源资产，不覆盖用户导出文件。

## 工作流映射

| 旧状态 | V3 状态 | 处理结果 |
|---|---|---|
| 阶段一、阶段二 | 前置阶段 | 合并为构图与 SU 可见细节文字审查 |
| 阶段三 | 优化阶段 | 保留结构底图、风格参考、提示词卡和生成结果 |
| 阶段四、final | 最终阶段 | 改为 D5 完整图的无蒙版整图玻璃深化 |
| Photoshop 交接 | review | 仅保留历史记录，不在画布继续执行 PS 流程 |

## 数据迁移规则

- 图片资产、原图／显示图／缩略图、版本、父子关系、任务链接、文字卡、批注、视口和视角名称全部保留。
- 每个视角补充 `preflight`、`sceneOptimization`、`finalGlass`、`export` 四组嵌套状态。
- 旧活动批次不会自动续跑；若升级时仍在排队或运行，将安全暂停并提示按 V3 规则重建，既有任务与结果不删除。
- 旧 `AI` 目录配置可兼容读取为最终导出目标；重新设置目录时会先备份旧配置。
- 新项目保存为 schema 2.0；桥接服务仍可读取 schema 1.0 项目并在画布保存时完成迁移。

## 操作边界

- 三阶段可从任一阶段直接开始，不设置跨阶段硬门禁。
- 前置阶段只返回文字；每张 D5 视角独立处理，可单独配一张 SU 截图。
- 优化阶段的“生成／优化提示词”和“按提示词生成图片”是两个独立动作。
- 最终阶段只接收 D5 完整图，不接收 SU、蒙版或通道图。
- 玻璃图须人工验收后才能选入导出集合；支持一个或多个版本。
- 导出按 `视角名_玻璃整图_01` 顺延命名，使用排他写入、不覆盖、按哈希去重，并保留逐项日志与部分成功记录。
- 全部选定成果导出成功后，画布任务结束；Photoshop 为画布外纯人工操作。

## 回退方式

- 原项目和升级前 Git 基线均保留。
- 若需回看旧行为，可从提交 `2fbd96e` 建立只读分支；不得用回退覆盖当前项目数据。
- 导出文件采用新文件名或顺延序号，撤销版本更新不会删除已经导出的成果。
