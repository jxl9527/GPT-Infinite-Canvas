## 1. 交付结论

本次升级已将现有 V3 画布落地为“一套工作流、两个执行器、同一份项目结果”的 A/B 双轨系统：

- **A｜人工批量**：保留现有批量提交、回收、版本管理和最终人工选图；Codex 额度不足或被其他任务占用时仍可独立工作。
- **B｜Codex 自动**：默认直接使用当前画布中已导入、已登记或框选的图片；需要新批次时也可从项目文件夹导入。确认授权单后，Codex 可通过本地插件和 12 个受限领域工具执行阶段任务、登记文字或图片结果并自动排版。
- **共同底座**：两种模式共用项目数据、三阶段语义、Run／RunItem 状态、检查点、版本关系和导出规则。
- **安全切换**：B 仅在安全检查点暂停或交接；A/B 不重复处理已完成项；不得静默降级。
- **人工决策**：Codex 不自动采用最终图片，正式导出仍由设计师确认。

## 2. 已完成范围

### 2.1 画布与执行层

- 右侧工具轨新增 A/B 执行方式抽屉。
- B 模式支持两种启动来源：默认从当前画布开始；需要新素材时再粘贴绝对路径或调用 Windows 系统选择器，只读扫描、角色识别、选择导入和运行授权。
- 当前画布来源按“框选图片 → 已准备批次 → 已登记 D5 视角 → 普通导入图”确定范围；风格参考和 SU 可见细节参考不会误入生图底图范围。
- B 模式阶段二在一次授权内连续完成提示词登记与图片生成；A 模式继续保留两个独立人工动作。
- 导入后按视角建立 D5 底图、SU 可见细节参考和风格参考关系。
- B 批次支持暂停、恢复、刷新结果和显式交接给 A。
- 修改意见位于原图左侧；生成结果位于原图右侧并纵向避让。

### 2.2 领域接口与状态安全

- 新增 Runner、授权单、租约、检查点、幂等键、尝试次数和内容哈希。
- Codex 只能通过领域 API 写入，不得直接编辑 `project.json`。
- 生成任务严格串行；超出目录、阶段、数量或生成上限立即拒绝。
- 结果先复制到项目资产区，再登记父子版本；源文件不被修改。
- 阶段二结构比例允许误差不超过 0.5%；阶段三最终玻璃图要求像素尺寸一致。
- 结构风险可自动暂停，但不得自动替代人工选图。

### 2.3 Codex 插件与安装

- 插件目录：`app/06_codex_integration/d5-ai-canvas`。
- 插件提供 12 个 `d5_*` MCP 领域工具和专用工作流 Skill。
- 本地 Marketplace：`app/06_codex_integration/.agents/plugins/marketplace.json`。
- 安装脚本：`app/05_installer_and_ops/Install-D5AICanvas-CodexPlugin.ps1`。
- 桌面安装器检测到 Codex 后可选装 B 模式；未安装插件时 A 模式不受影响。
- 连接发现文件只记录 URL、运行目录和版本；Token 仍保存在运行目录，不写入插件配置或发现文件。

## 5. 生产启用边界

本轮没有在未获授权的情况下消耗 Codex 图片生成额度。D5 AI Canvas 插件 0.5.2 已通过安装器写入当前用户 Codex 配置，安装前已自动备份配置；正式 Bridge 已更新到 0.5.2，并完成真实 MCP 协议调用和独立发布包联调。

正式启用时执行：

```powershell
pwsh.exe -File .\app\05_installer_and_ops\Install-D5AICanvas-CodexPlugin.ps1
```

重启 Codex 后，在画布中框选一张或多张已导入图片，打开右侧“A/B 执行方式”，选择 B 和“当前画布”，再确认阶段、项目范围和最大生成张数即可。只有导入新批次时才切换“项目文件夹”。阶段二固定连续执行“提示词 → 生成图片”。建议首个生产批次使用 1 个视角、1 张生成上限；确认结构保护、结果归位和人工采用无误后再扩大批量。

## 6. 不可回归原则

1. 三阶段继续独立直入，不增加跨阶段强制门槛。
2. 项目源文件只读，导入和生成均另存到项目资产区。
3. B 模式必须有明确授权单，不能扫描整盘或越权扩展范围。
4. A/B 交接必须基于检查点和幂等键，已完成项不得重复生成。
5. 图一只作风格参考、图二为唯一结构依据时，任何自动化不得改变图二建筑与场地关系。
6. Codex 只生成、校验和排列候选，最终采用与正式导出由设计师确认。
