## 3. 用户已确定的产品方向

1. 固定提示词库采用参考图式卡片/图库页面。用户先给参考图，AI 提炼提示词，再固定收录。
2. 使用时从提示词库复制，进入画布导入/选中图片，粘贴提示词，启动网页生成，结果归入对应原图。
3. 自动生成继续走现有 ChatGPT 网页发送与回收，不能擅自改为 API 生图。
4. 默认两项并发，可退回单项；每项独立网页、独立归属。用户实测同账号两个网页可以同时生成。三项并发尚未批准为默认，也未验证。
5. “简化”指减少复杂工作流，不是删除中键、缩放、选区、撤销等基础功能。
6. 建筑图像必须保护原始结构、视角、道路及场地边界。参考风格不能覆盖结构基准。

计划书见 [无限画布简化改版项目计划书](无限画布简化改版项目计划书.md)。README 后半部分主要描述旧兼容入口，不应反向作为简化版需求。
