# 2026-09-13 画布布局精简实施与首页增强

依据：[画布布局精简与生成参数前置计划书](../画布布局精简与生成参数前置计划书.md)（该计划由另一窗口规划）。用户在本轮追加：导入入口移入设置、设置更名、首页删除项目、字体改 Noto Serif SC、底部提示不靠边。

## 1. 本轮目标与结论

按计划完成画布页布局精简（顶部合并、右侧压缩、工具栏竖排、生成参数前置），并按用户追加要求完成导入入口迁移、首页项目删除、字体替换与底部提示居中。业务语义（多版本、三并发、对比、排程、扩展协议）未改。

## 2. 完成事项

### 2.1 计划内布局

- 顶部：画布页隐藏品牌/导航层（`SimpleWorkspace` 仅在非“已打开画布的画布页”输出 `sg-shell`），只保留约 48px 单层项目栏；项目名单行省略并带 `title` 查看全名。
- 右侧：删除“图片渲染”和大号“已选择N张图片”，改为一行紧凑上下文（单选 `1张 · 文件名`；多选 `已选N张 · 查看图片` 可展开）；未选但批次存在时显示“本轮任务”，队列与暂停/检查保持可见。
- 参数前置：提示词框下方两列「同时生成 / 每张图生成」，设置页删除这两项和长段机制说明，仅保留一句指引；活动批次期间两项禁用并显示“本轮进行中，完成后可调整”；下方一行显示 `字数 / 20000 · 已选N张 · 共M个任务`。
- 左侧竖排工具栏（`BasicCanvas`）：`sg-canvas-tools` 改为 50px 宽竖排浮层，按「选择/平移｜文字/箭头/画笔/矩形/颜色｜撤销/重做/适合画面｜整理菜单」分组；全部使用内联 SVG 图标，`title` 显示中文名+快捷键，`aria-label` 可用；整理菜单向右弹出；适合画面把左侧工具轨与底部条计入可视区。
- 底部条：缩放按钮与提示整组在画布内居中，对象列表固定在右下（`sg-canvas-bottom-main`）；图片选中工具条与底部条左移避开工具轨。
- 状态提示短时化：`use-simple-project` 的 `setNotice` 支持 `{ sticky: false }`，成功提示 4 秒消失；保存/连接/锁定等持久问题保持可见。

### 2.2 用户追加

- 顶部「导入图片」按钮移除，「导出 / 设置」更名为「设置」；导入操作移入设置面板（`选择图片文件` / `导入文件夹`），原先埋在“连接与兼容”里的“导入文件夹”合并到同一区，避免重复入口。
- 首页项目列表新增行内删除：`删除` → 行内确认（提示会移入本地回收目录）→ 调用既有 `deleteWorkbenchProject` 软删除；`原有项目`（`project_default`）不显示删除；删除当前打开的画布时先解除绑定与实例再删除；服务端在存在生成任务或未完成 Codex 批次时拒绝并显示原因。删除后列表刷新并显示约 4 秒提示。
- 主界面字体改为 `"Noto Serif SC", "Microsoft YaHei UI", "Microsoft YaHei", serif`，正文 `font-weight:500`、标题 600（系统已安装 `NotoSerifSC-VF.ttf` 可变字体）。
- 多结果命名（上一轮遗留）：同一任务返回多张图片时按 `_1`、`_2` 后缀命名，全部保留。
