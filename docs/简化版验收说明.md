# 简化版 0.6.0 验收说明

日期：2026-09-12。分支：agent/canvas-simple-prompt-library。配套扩展：1.6.0。

## 日常流程

提示词库选择卡片 → 复制提示词 → 画布选择项目 → 导入或选中底图 → 粘贴提示词 → 开始渲染。

每张底图独立发送到 ChatGPT 新会话。默认最多两项同时生成，提交依次进行；一项完成后补入下一项。结果放在对应原图右侧，原图保留。“导出 / 设置”可改为单任务、导出所选图片或打开旧版兼容工作台。

正在执行的提示词按批次冻结。修改输入框只影响下一轮。暂停停止补入新任务，已提交任务仍可回收；停止后续任务取消未发送项目。已提交但网页关闭的任务不会自动重发，可结束本地跟踪后明确重新生成。

## 安装与升级

1. 解压独立安装包，沿用安装与使用说明中的启动程序。
2. Chrome 扩展应加载发布包的 `03_browser_extension/dist`，确认版本为 1.6.0。已有扩展须重新加载，然后刷新画布页面。
3. 桥接服务与前端均须为 0.6.0。存在未结束旧任务时，启动器会阻止直接升级；先在旧工作台处理该任务。
4. 旧项目运行数据不包含在安装包内。更换安装目录时先备份旧 runtime，再复制到新版对应位置，禁止覆盖唯一原件。原工作区旧任务没有被本次交付强制结束。

## 真实网页验收

用户已实测同一 ChatGPT 账号两个网页可同时生成。本次自动化回归使用隔离测试回包，未把它当作真实 ChatGPT 生图实测。

升级后用三张非重要底图验收：先出现两个独立会话；每个会话只上传自己的底图；任意一项完成后自动回收并补入第三项；刷新画布不重复发送；三张结果分别对应原图。真实网页登录状态、上传和结果检测仍须以这次实测为准。

图库目前为六张基础文字模板，封面明确标注“示意”。用户提供清晰参考图后，按《提示词内容包说明》整理真实案例卡片。
